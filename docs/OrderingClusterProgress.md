# Ordering entropy as connected-region counting

## What changed

Continuation: [larger-box sampling and an event-probability bound](ClusterStatisticsProgress.md)
now test both ensembles through side 8. The results caution against using
either mean as a sharp entropy estimate; the full area law is still open.

The residual weak-ordering cost now has an exact cluster representation,
proved in `CAGOrderingClusters.lean`. The ownership constraints are generated
by immediate causal comparisons. Two explicit sampling ensembles give
rigorous finite upper and lower entropy bounds.

This does not prove the conjectured four-dimensional area law, establish
novelty in the literature, or derive gravitational dynamics. It sharpens
the unresolved question from a ratio of counts to the distribution of
connected disagreement regions.

## The switching bijection

Continue the notation of [the first entropy test](CompatibilityEntropyGravityTest.md):
`H` is the number of antitone profiles on `[m]^d` with heights `0,...,m-1`,
and `Q` is the number of weakly ordered pairs of such profiles. These
weak pairs are in bijection with the original strictly separated pairs.
Ambient dimension is `d+1`.

Take two arbitrary profiles `a,b` and sort them pointwise:

```
lower = min(a,b),    upper = max(a,b).
```

At a base point where the boundaries disagree, one must remember which
input profile supplied the lower height. If `x <= y` and
`lower(x) < upper(y)`, their nonempty height intervals overlap, forcing
the same ownership choice. Otherwise switching the choices independently
would violate antitonicity of one of the original profiles.

Let `c(lower,upper)` be the number of connected components generated by
these overlap constraints on the disagreement points. Then

```
sorting fiber over (lower,upper)  <->  {one Boolean choice per component},
number of preimages = 2^c,
H^2 = sum_(lower <= upper) 2^c.
```

Every choice reconstructs two valid antitone profiles; different choices
give different pairs. The empty disagreement set has `c=0` and one
preimage, not two. Lean checks the actual bijection and cardinality
identity in every base dimension and box side.

`BandComponent` is defined as the quotient by the relation generated by
overlap, so its classes are the connected regions, not an assumed number
or a fitted parameter. This representation reuses the existing
strict-to-weak equivalence; that equivalence was not newly discovered here.

## Exactly what is local

The theorem `overlap_invariance_iff_cover_invariance` proves that it is
enough to enforce ownership agreement along immediate causal comparisons
(`CovBy`, the Hasse edges of the base poset) when the intervals overlap.

Proof idea: any comparable base points are joined by a chain of covers.
If their height intervals overlap, antitonicity keeps the intermediate
intervals overlapping along that chain. Equality of ownership therefore
propagates using just the immediate comparisons.

This is locality of the constraints. It is NOT a proof that their entropy
is a sum of independent local area contributions: a connected region can
extend through the whole box. No continuum limit or spacetime metric is
introduced by the theorem.

## The two ensembles must not be confused

Let `O` denote a uniformly selected ordered pair among the `Q` choices.
Let `I` denote two independent uniformly selected profiles among the `H^2`
choices, followed by sorting. Their distributions of sorted boundaries
are different: ensemble `I` weights an ordered pair by `2^c`.

The exact formulas are

```
W = log(H^2/Q)
  = log E_O[2^c]
  = -log E_I[2^(-c)],

(log 2) E_O[c] <= W <= (log 2) E_I[c].
```

Lean checks the change-of-ensemble identity for every real observable of
the component count, the inverse-moment identity, and the two-sided
Jensen bounds. All expectations are explicit finite sums. In particular,
the upper bound uses the INDEPENDENT-profile mean, not the uniform-ordered
mean. Replacing one with the other would invalidate the argument.

For four ambient dimensions, an estimate `E_I[c] <= C*m^2` would therefore
be sufficient to prove an area upper bound for `W`, hence for the whole
compatibility deficit. This sufficient estimate has not been proved and
need not be necessary. An area upper bound would still fall short of a
positive limiting area coefficient.

The inverse-moment identity also supplies an unbiased estimator for
`Q/H^2` if truly independent uniform profiles can be sampled. It does
not automatically give low relative variance or an efficient sampler;
taking a logarithm of an empirical mean introduces another estimation
issue. The [subsequent statistical investigation](ClusterStatisticsProgress.md)
addresses larger boxes with separate uncertainty bounds.

## Why a worst-case component bound cannot close the problem

There is an elementary obstruction inside the SAME four-dimensional
trimmed-box model, not a different family of posets. Write

```
P = [m]^3 x [m-1],   m >= 2,
rank(x) = sum of the four coordinates.
```

For any integer `r`, both `L={rank<r}` and `U={rank<=r}` are ideals.
Their difference is a rank layer. All its elements are incomparable,
so each is an isolated disagreement component. Under the profile encoding,
each active base column contains exactly one such cell and distinct
comparable columns have non-overlapping bands.

There are `m^3*(m-1)` cells but only `4*(m-1)` possible ranks. By
pigeonhole, some layer therefore gives

```
c >= m^3/4.
```

It follows that no uniform pointwise bound `c <= C*m^2` can hold for all
ordered pairs as `m` grows. This does NOT disprove an area law for `W`:
the probability and exponential weighting of these fragmented boundaries
remain decisive.

The rank-layer argument in this section is a written elementary proof,
not yet an all-side Lean theorem. The script checks exact rank-layer
coefficients, and the tests construct the actual bands for sides 2–5,
checking downset validity and isolation in both component representations.

## Research consequence and remaining work

The present result supplies a locally constrained cluster-counting model
for CAG's residual ordering entropy. It does not identify these clusters
with matter, gravitational degrees of freedom, or horizon microstates.

The next mathematical step is statistical: control the relevant component
distribution, through the independent mean, the ordered exponential
moment, or suitable tail bounds. Highly fragmented rank-layer examples
explain why deterministic counting of all possible components is too coarse.

For the gravitational interpretation, locality and robustness of the
entropy functional itself remain open. Source constraints, a separation
parameter, thermodynamic inputs, and an interaction law are still absent.
