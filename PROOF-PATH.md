# CAG proof path

This file is the small verification map for the default
`CausalAlgebraicGeometry` library target.  It separates checked endpoints,
conditional results, conjectures, and deliberately excluded experimental
targets.

## Audited endpoints

`CausalAlgebraicGeometry/FinalCheck.lean` exposes and audits these results:

1. `checked_dimension_law`: explicit lower and upper bounds in every
   dimension `d ≥ 2`.
2. `checked_growth_constant`: the two-dimensional convex-set growth constant
   is exactly 16.  This endpoint uses `native_decide`, so its pinned report
   includes `Lean.ofReduceBool` and `Lean.trustCompiler`.
3. `checked_c3_entropy_factorization`: unconditional two-boundary entropy
   factorization at area scale.
4. `checked_cspec_sheaf`: the generated causal spectrum carries an actual
   Mathlib sheaf of types.
5. `checked_rational_chamber_factorization`: the rational chamber polynomial
   has its distinguished rational linear factor.
6. `checked_chamber_galois_faithful`: the residual polynomial's genuine
   splitting-field Galois action is faithful.
7. `checked_cspec_ring_sheaf`: causal-corner fibres form a genuine sheaf of
   noncommutative unital rings.
8. `checked_generic_chamber_specialization`: the parameterized chamber family
   specializes exactly to the rational recurrence at `δ = d`.
9. `checked_q4_frobenius_seed`: the `d = 4` residual has a complete mod-11
   factorization certificate with degree pattern `[2]`.  Its exhaustive
   finite-field checks use `native_decide`, so the pinned report records the
   corresponding compiler-trust dependencies.
10. `checked_cspec_chamber_root_sheaf`: local chamber-root choices form a
    genuine sheaf over CSpec.
11. `checked_local_chamber_galois_faithful`: each local splitting-field action
    is faithful.
12. `checked_full_chamber_galois_four`: the canonical residual Galois action
    in dimension four is the full symmetric group `S₂`.
13. `checked_q4_frobenius_cycle_bridge`: the certified mod-11 pattern `[2]`
    is realized by an actual characteristic-zero Galois element.
14. `checked_chamber_root_stratified_constant`: local root fibres are
    canonically equivalent on every fixed-dimension stratum.
15. `checked_unstratified_root_local_system_fails`: the two-element chain is
    an explicit counterexample to unrestricted local constancy.
16. `exists_curvatureDensity_tendsto_subseq`: normalized curvature along any
   refinement tower has a convergent subsequence.

Run only this verification surface with:

```bash
lake build CausalAlgebraicGeometry.FinalCheck
```

Every `#print axioms` result is wrapped in `#guard_msgs`; adding `sorry`, a
new axiom, or a new compiler-trusted dependency to an endpoint therefore
breaks this target.

## Chamber Galois path

The checked chain is:

```text
rational recurrence
  → exact base change to the existing real recurrence
  → rational structural root
  → residual polynomial of degree d - 2
  → canonical splitting field and faithful root action
  → integral-model/factorization certificate interface
  → complete d = 4, p = 11 certificate with pattern [2]
  → irreducible quadratic and transitive two-root action
  → full d = 4 symmetric group S₂ and an actual two-cycle
```

Surjectivity is now a theorem for `d = 4`.  Its uniform all-dimensional form
is stated as `ChamberGaloisConjecture`; it is not asserted as a theorem.
Per-d finite-field factorization certificates can be added as kernel-checked
data.  The theorem carrying a squarefree certified factor pattern (with
degree-one factors omitted because Mathlib's `cycleType` omits fixed points)
to a characteristic-zero Galois cycle remains the explicit
`FrobeniusCycleBridgeStatement`.  The uniform all-`d` argument remains open
mathematics.

`ChamberGenericFamily.lean` also supplies a fixed-shape family over an
arbitrary field, its specialization theorem over `ℚ`, and the generic member
over `ℚ(δ)`.  The generic structural-root and full-symmetric Galois assertions
are exposed as `GenericStructuralRootStatement` and
`GenericChamberGaloisConjecture`, not assumed.

### Status of the four chamber targets

| Target | Kernel-checked status |
|---|---|
| Full chamber symmetry | Proved for `d = 4`; uniform `d ≥ 4` remains conjectural. |
| Frobenius bridge | Proved for the certified `d = 4`, `p = 11` pattern; the corrected squarefree general bridge remains open. |
| Generic Galois symmetry | The family and specialization are proved; generic full symmetry remains open. |
| Root-sheaf local constancy | False without hypotheses; fixed-dimension constancy and the dimension-locally-constant implication are proved. |

## CSpec sheaf path

`CSpecActualSheaf.lean` defines the topology generated by
`D(a) = {P | a ∉ P}`, assigns to each point the corner type on the convex
complement of its causal prime, and constructs a genuine
`TopCat.Sheaf (Type _)`.  `CSpecRingSheaf.lean` equips the same fibres with
their diagonal local identities and noncommutative corner multiplication,
and proves restriction is a unital ring homomorphism.  `CausalSchemeData`
stores both the underlying type sheaf and the `RingCat` structure sheaf.

`CSpecChamberRoots.lean` indexes residual chamber polynomials by the finite
complement of each causal prime, constructs the associated root-choice sheaf,
and proves faithfulness of every local Galois action.  It proves constancy on
each fixed-local-dimension stratum and proves that a locally constant dimension
function suffices for an unstratified local system.
`CSpecChamberRootsCounterexample.lean` proves the unrestricted statement false
in general: on the two-element chain, every neighbourhood of the upper prime
also contains the generic prime, while their root fibres have cardinalities
one and two.

## Conditional and excluded claims

- The numerical cubic constant in `C3AsymptoticClosure.lean` is conditional
  on the stated classical MacMahon cubic-box asymptotic.  The entropy
  factorization endpoint above is unconditional.
- `RHTarget.lean` is an experimental target containing four explicit custom
  axioms.  It is not imported by `CausalAlgebraicGeometry.lean` or
  `FinalCheck.lean` and is not part of the audited default claim.
- Documentation-only status files do not create theorem-level claims.

## Reproducibility boundary

The project stays pinned to Lean/Mathlib v4.28.0.  The Anthropic FLT project
uses a newer toolchain, so CAG does not add it as a Lake dependency.  The
reused ideas are architectural and Mathlib-facing; the implementations here
are small native CAG modules that can be reviewed and upgraded independently.
